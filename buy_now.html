No. The license key is tied to your machine, so there is nothing to register and nothing to sign into.
Will it work on more than one computer?
One license covers one PC. If you need a second machine, just email me and we can sort it out.
Which Windows versions are supported?
Windows 10 and Windows 11. It needs the Microsoft .NET Desktop Runtime, which Windows usually offers to install for you on first run.
What happens if I replace my motherboard?
Your machine code changes, so the old key stops validating. Send me your purchase details and I'll re-activate it for you.
